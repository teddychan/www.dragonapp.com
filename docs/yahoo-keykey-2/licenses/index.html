libtabe / TaBE phrase data BSD-style

McBopomofo's phrase data (BPMFMappings.txt) is itself derived from libtabe's tsi.src, released by the TaBE project under a BSD-style license (TaBE project, Pai-Hsiang Hsiao et al.). That license asks for the attribution to be preserved, so it is preserved here and in the app's repository.

Attribution retained per the upstream notice; reached through McBopomofo.

Cangjie 5 table (倉頡第五代) Freely redistributable

The bundled 五代倉頡 table (cangjie.txt) is derived from the Cangjie-5 table in definite/ibus-table-chinese (tables/cangjie/cangjie5.txt). Only the data table is reused, under the table file's own declaration; the surrounding repository packaging is GPLv3 and is not used.

Upstream data origin: chinesecj.com (倉頡之友‧馬來西亞), CangJie Input Method the 5th Generation (2008 Latest Edition).

Source: definite/ibus-table-chinese

Yahoo! KeyKey 三代 tables (倉頡第三代 / 速成) New BSD

The bundled 三代 tables (cangjie-yahoo.txt, simplex-yahoo.txt) are extracted from the open-sourced Yahoo! KeyKey source release (DataTables/cj-ext.cin, DataTables/simplex-ext.cin), which is released under the New BSD license. Both tables are the “large character set” builds based on opendesktop.org.tw's cj.cin / simplex.cin, merged and extended by yylin and b6s.

The table files carry no per-file license line; reuse here relies on the project's BSD release and the OpenVanilla-community (opendesktop.org.tw) origin of the tables. Only the data tables are reused — Yahoo! KeyKey 2 uses no source code from the project.

The release's own COPYING says “Refer to individual source code header for copyright notices”, and scopes its Copyright (c) 2007-2010 Yahoo! Taiwan line to projects under PreferenceApplications/ and Utilities/ — not DataTables/. That line is recorded as provenance; the notice below is the project's own, from the repository's LICENSE, reproduced in full because BSD-3-Clause requires a binary redistribution to carry the copyright notice, the conditions and the disclaimer.
