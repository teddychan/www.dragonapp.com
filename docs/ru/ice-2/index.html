Менеджер строки меню для macOS

Наведите порядок в строке меню на современной macOS

Ice 2 скрывает ненужные значки в строке меню. Каждый значок либо показан, либо скрыт, а скрытые ждут в панели Ice Bar под значком Ice. Бережно воссозданная версия с открытым кодом, теперь сделанная для macOS 27.

Показ или скрытие каждого значка

В настройках выберите «Показать» или «Скрыть» для каждого значка в строке меню. В macOS 27 выбор действует на все значки приложения.

Ice Bar

Нажмите значок Ice, чтобы увидеть скрытые значки в панели под ним. Нажмите один из них, чтобы открыть его меню.

Единый порядок

Перетаскивайте значки в Ice Bar или в настройках. В обоих местах порядок одинаковый.
