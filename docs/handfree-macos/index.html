Voice dictation for macOS

HandFree for Mac

Hold a shortcut, speak, and let go. HandFree cleans up what you said and inserts the text at your cursor.

GitHub release Download and install

macOS 14 or later · Apple silicon · English, Simplified and Traditional Chinese · GitHub and Homebrew

See it in action

Dictate where you type

Hold a keyboard shortcut or mouse button in the app you're using. Release to insert the text where your cursor is.

Clean up as you go

HandFree can remove filler words, fix slips, and add punctuation and paragraphs. Add names and terms to your personal vocabulary.

Choose your speech engine

Recognize speech on your Mac with Qwen3-ASR, or bring your own API key for a cloud provider. Text cleanup uses the model you choose.
